HOW TO USE 
-> download the version1.1 available on the repository (https://github.com/AnujJain31/quadratic-graphmaker/releases/tag/stable)
-> Write a quadratic equation of the form (ax^2 + bx + c = 0)
-> Click PLOT button to see the graph of the equation slowly appear on the graph screen.
